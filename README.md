# 📝 CodeSnippet

A web application for saving, viewing, editing, and deleting reusable code snippets. The app is deployed with Vercel and uses Supabase PostgreSQL for persistent storage.

## 🚀 Quick Start

### Prerequisites

- Node.js 20+
- npm or yarn

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/nitin8217/CodeSnippet.git
   cd CodeSnippet
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Configure Supabase**
   ```bash
   # Windows PowerShell
   Copy-Item .env.example .env

   # macOS/Linux
   cp .env.example .env
   ```

   Replace the placeholder values in `.env` with the values from Supabase:
   - `NEXT_PUBLIC_SUPABASE_URL`: Project URL
   - `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`: Publishable key

   Then create the table by opening **Supabase Dashboard → SQL Editor**, pasting [`supabase/schema.sql`](./supabase/schema.sql), and clicking **Run**.

4. **Start development server**
   ```bash
   npm run dev
   ```

5. **Open in browser**
   ```
   http://localhost:3000
   ```

## 🚀 Deploy to Vercel

This is the simplest way to publish the app.

### 1. Create the Supabase table

1. Open your Supabase project.
2. Go to **SQL Editor**.
3. Open [`supabase/schema.sql`](./supabase/schema.sql), copy all of its contents, and paste it into a new query.
4. Click **Run**.

The script creates the `Snippet` table and the policies needed by the app.

### 2. Push the project to GitHub

```powershell
cd D:\codesnippet
git add .
git commit -m "Prepare Supabase deployment"
git push origin main
```

### 3. Import the repository into Vercel

1. Open [vercel.com](https://vercel.com) and sign in with GitHub.
2. Click **Add New → Project**.
3. Select the `CodeSnippet` repository.
4. Keep the default framework as **Next.js**.
5. Keep the default build command: `npm run build`.

### 4. Add environment variables

In the Vercel project setup, open **Environment Variables** and add:

```text
NEXT_PUBLIC_SUPABASE_URL=https://your-project-ref.supabase.co
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=sb_publishable_your-key
```

Add them for **Production**, **Preview**, and **Development**, then click **Deploy**.

### 5. Verify the deployment

Open these URLs using your Vercel domain:

```text
https://your-project.vercel.app
https://your-project.vercel.app/api/health
```

Create a test snippet and confirm that it appears in the Supabase table.

The Vercel build should finish with a successful `Next.js 15.5.28` production build.

### Important security note

The current app has no login system. The SQL policies intentionally allow public users to read, create, edit, and delete snippets. Anyone with access to the deployed app can therefore modify its snippets. Add authentication and user-specific policies before using it for private or sensitive code.

## 🔧 Environment Variables

Create a local `.env` file from `.env.example`. Do not commit `.env`.

```bash
# Supabase project URL
NEXT_PUBLIC_SUPABASE_URL="https://your-project-ref.supabase.co"
# Supabase publishable key
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY="sb_publishable_your-key"
PORT=3000
```
